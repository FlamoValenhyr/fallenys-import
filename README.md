<img width="512" height="250" alt="image" src="https://github.com/user-attachments/assets/87ec2469-2093-49d9-b651-9efb235faacd" />## Fallenys Import

Outil Windows de la guilde Fallenys : après une partie personnalisée, il lit la partie dans ton client League of Legends
(lecture seule) et l'envoie sur https://fallenys.valenhyr.fr. Ton code personnel se génère sur le site, page Historique.

### Premier lancement : avertissement de Windows

Fallenys Import est un petit outil communautaire qui n'est pas signé par un certificat d'éditeur (payant). Au premier
lancement, Windows peut donc afficher « Windows a protégé votre ordinateur ».

1. Clique sur **Informations complémentaires**.
2. Vérifie que l'application s'appelle bien **FallenysImport.exe**, puis clique sur **Exécuter quand même**.

Windows ne le redemandera plus pour ce fichier.

### Utilisation

1. Après la custom, client League of Legends ouvert, lance Fallenys Import et colle ton code (la première fois seulement).
2. Clique sur **Importer** à côté de la partie : elle apparaît sur le site si les 10 joueurs y sont inscrits.

Fallenys n'est ni approuvé ni sponsorisé par Riot Games.
